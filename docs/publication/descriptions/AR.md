ELEMENT COPIER
انسخ ونزّل أي جزء من الصفحة بتنسيقات مختلفة. للمهام اليومية والمهنية.

الميزات
- نسخ صفحة كاملة أو عنصر محدد،
- تحويل المعلومات إلى عدة صيغ في وقت واحد،
- الاحتفاظ بآخر محتوى منسوخ لكل الصيغ،
- السمات الفاتحة والداكنة،
- إعدادات مرنة.

صيغ النسخ
للعمل مع المحتوى: نص جاهز للصق في المستندات، وصور PNG أو JPEG، ونص منسق للملاحظات والتوثيق (Markdown).
للتطوير والاختبار وتقارير الأخطاء: رمز الصفحة والعنصر المحدد، وأنماطه، وطرق تحديد العنصر بدقة: محدد CSS، ومسار JS، وXPath، وXPath الكامل، أو tag#id.class.

الأمان
- لا تتعقب المستخدمين،
- لا تجمع ولا تنقل البيانات.
