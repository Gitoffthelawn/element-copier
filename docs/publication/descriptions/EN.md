ELEMENT COPIER
Copy and download any part of a page in different formats. For everyday work and professional tasks.

FEATURES
- Copy an entire page or a specific element,
- Convert information into multiple formats at once,
- Keep the last copied content for all formats,
- Light and dark themes,
- Flexible settings.

SUPPORTED FORMATS
- Rich text for pasting into Google Docs and Word,
- Images (PNG, JPEG),
- Markdown,
- Page source code,
- Many formats for developers and testers:
   - HTML,
   - Tag#id.class,
   - Selector,
   - JS path,
   - XPath,
   - full XPath,
   - declared and computed styles,
   - QA details for bug reports.

SECURITY
- Does not track users,
- Does not collect or transmit data.

INTERFACE LANGUAGES
English, French, German, Spanish, Russian, Arabic, Simplified Chinese.
