ELEMENT COPIER
Copiez et téléchargez n’importe quelle partie d’une page dans différents formats. Pour les tâches quotidiennes et professionnelles.

FONCTIONNALITÉS
- Copier une page entière ou un élément précis,
- Convertir les informations en plusieurs formats à la fois,
- Conserver le dernier contenu copié pour tous les formats,
- Thèmes clair et sombre,
- Paramètres flexibles.

FORMATS PRIS EN CHARGE
- Texte enrichi pour le collage dans Google Docs et Word,
- Images (PNG, JPEG),
- Markdown,
- Code source de la page,
- De nombreux formats pour les développeurs et les testeurs :
   - HTML,
   - Tag#id.class,
   - Sélecteur,
   - Chemin JS,
   - XPath,
   - XPath complet,
   - Styles déclarés et calculés,
   - Détails QA pour les rapports de bugs.

SÉCURITÉ
- Ne suit pas les utilisateurs,
- Ne collecte ni ne transmet de données.

LANGUES DE L'INTERFACE
Anglais, français, allemand, espagnol, russe, arabe, chinois simplifié.
