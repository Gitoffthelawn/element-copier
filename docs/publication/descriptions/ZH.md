ELEMENT COPIER
以多种格式复制和下载网页的任意部分。适用于日常工作和专业任务。

功能
- 复制整页或某个元素，
- 一次将信息转换为多种格式，
- 为所有格式保留最近一次复制的内容，
- 浅色和深色主题，
- 灵活的设置。

支持的格式
- 用于粘贴到 Google Docs 和 Word 的富文本，
- 图片（PNG、JPEG），
- Markdown，
- 页面源码，
- 面向开发者和测试人员的多种格式：
   - HTML 代码，
   - Tag#id.class，
   - 选择器，
   - JS 路径，
   - XPath，
   - 完整 XPath，
   - 声明式样式和计算后样式，
   - QA 详情用于缺陷报告。

安全性
- 不跟踪用户，
- 扩展不收集也不传输数据，
- 点击、键盘输入和设置仅保存在浏览器本地。

界面语言
英语、法语、德语、西班牙语、俄语、阿拉伯语、简体中文。
