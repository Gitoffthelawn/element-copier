ELEMENT COPIER
Kopieren und laden Sie jeden Teil einer Webseite in verschiedenen Formaten herunter. Für alltägliche und professionelle Aufgaben.

FUNKTIONEN
- Ganze Seite oder ein bestimmtes Element kopieren,
- Informationen gleichzeitig in mehrere Formate umwandeln,
- Den zuletzt kopierten Inhalt für alle Formate speichern,
- Helles und dunkles Design,
- Flexible Einstellungen.

UNTERSTÜTZTE FORMATE
- Rich Text zum Einfügen in Google Docs und Word,
- Bilder (PNG, JPEG),
- Markdown,
- Seitenquellcode,
- Viele Formate für Entwickler und Tester:
   - HTML,
   - Tag#id.class,
   - Selektor,
   - JS-Pfad,
   - XPath,
   - vollständiger XPath,
   - deklarierte und berechnete Styles,
   - QA-Details für Fehlerberichte.

SICHERHEIT
- Sie verfolgt keine Benutzer,
- Die Erweiterung erfasst und überträgt keine Daten,
- Klicks, Tastatureingaben und Einstellungen werden lokal im Browser gespeichert.

OBERFLÄCHENSPRACHEN
Englisch, Französisch, Deutsch, Spanisch, Russisch, Arabisch, vereinfachtes Chinesisch.

Ich hoffe sehr, dass diese Erweiterung für Sie nützlich sein wird 🙌
